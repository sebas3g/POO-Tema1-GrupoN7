# POO - Tema 1: Clase Estudiante

## 1. Objetivo

Comprender y aplicar los conceptos fundamentales de la Programación Orientada a Objetos (POO) mediante el diseño e implementación de una clase en Java, identificando sus atributos, creando objetos y utilizando GitHub para organizar el código y evidenciar el trabajo colaborativo.

## 3. Descripción del proyecto

El proyecto consiste en desarrollar una clase denominada `Estudiante` para representar la información básica de los estudiantes de la Universidad Técnica de Ambato.

La clase contiene cinco atributos: nombre, apellido, edad, carrera y semestre. Mediante la clase `Principal`, se crean tres objetos de tipo `Estudiante`, cada uno con información diferente, y se muestran sus datos en la consola.

Este ejercicio permite comprender la relación entre las clases, los atributos y los objetos dentro de la programación orientada a objetos.

## 4. Diagrama de la clase

El siguiente diagrama representa la estructura de la clase `Estudiante` y los atributos que la conforman.

```text
+----------------------------------+
|            Estudiante            |
+----------------------------------+
| - nombre: String                 |
| - apellido: String               |
| - edad: int                      |
| - carrera: String                |
| - semestre: int                  |
+----------------------------------+
```

**Descripción de los atributos:**

- `nombre`: nombres del estudiante.
- `apellido`: apellidos del estudiante.
- `edad`: edad del estudiante.
- `carrera`: carrera universitaria que cursa.
- `semestre`: semestre académico en el que se encuentra.

## 5. Tecnologías utilizadas

- **Lenguaje:** Java.
- **Entorno de desarrollo:** Visual Studio Code o Apache NetBeans.
- **Control de versiones:** Git.
- **Repositorio:** GitHub.

## 6. Instrucciones de ejecución

1. Descargar o clonar el repositorio desde GitHub.
2. Abrir el proyecto en Visual Studio Code o Apache NetBeans.
3. Verificar que Java esté instalado y configurado correctamente.
4. Comprobar que los archivos `Estudiante.java` y `Principal.java` estén incluidos.
5. Ejecutar la clase `Principal`, que contiene el método `main`.
6. Revisar la consola y comprobar que se muestre la información de los tres estudiantes.

## 7. Resultados esperados

Al ejecutar el programa, se debe visualizar la información de tres estudiantes diferentes, incluyendo su nombre, apellido, edad, carrera y semestre.

## 8. Conclusión

El desarrollo de este proyecto permite comprender cómo se define una clase en Java, cómo se organizan sus atributos y cómo se crean varios objetos con información independiente. Asimismo, el uso de GitHub facilita la organización de los archivos, el registro de cambios y la colaboración entre los integrantes del equipo.
